# Pigeon Game

A pigeon video game created together by Monica and her husband.

## Project structure

- `docs/` - Game design, art direction, technical planning, roadmap, and decisions.
- `game/` - Game source code and project files.
- `assets/` - Art, audio, fonts, and other game assets.
- `prototypes/` - Experiments and gameplay prototypes.

## Getting started

The project is in its initial planning stage. Start with
[`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md) and record important choices in
[`docs/DECISIONS.md`](docs/DECISIONS.md).
