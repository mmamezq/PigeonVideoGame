# Pigeon Game

A pigeon video game created together by Monica and Edoardo.

A disgraced Modena pigeon knight, cast out of his roost after losing a duel,
travels medieval Emilia-Romagna on his own. Along the way he relearns the lost
art of pigeon displays and earns a rematch with the rival who beat him. It's a
cute, heartfelt isometric RPG with real-time bird-vs-bird combat.

## Project structure

- `docs/` - Game design, story, art direction, technical planning, roadmap, and
  decisions.
- `game/` - Game source code and project files.
- `assets/` - Art, audio, fonts, and other game assets.
- `prototypes/` - Experiments and gameplay prototypes.
