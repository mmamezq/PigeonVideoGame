# Pigeon Game

A pigeon video game created together by Monica and Edoardo.

## Project structure

- `docs/` - Game design, art direction, technical planning, roadmap, and decisions.
- `game/` - Game source code and project files.
- `assets/` - Art, audio, fonts, and other game assets.
- `prototypes/` - Experiments and gameplay prototypes.

> **Combat (temporary note, 2026-11-15):** You play a round, armored Modena pigeon in deliberate one-on-one duels: wing slaps, pecks and kicks with readable warning animations, and twin-stick controls where movement and facing are separate. We're about to build a small 2D prototype to test whether this feels good. Current status: [`docs/COMBAT_STATUS.md`](docs/COMBAT_STATUS.md).

## Getting started

The project is in its initial planning stage. Start with
