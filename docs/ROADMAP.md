# Roadmap

## Phase 1: Concept

- Define the high concept and core gameplay loop.
- Choose the game engine and target platform.
- Establish the visual direction.

## Phase 2: Prototype

- Build a playable movement prototype.
- Test the core mechanic.
- Identify the biggest design and technical risks.

## Phase 3: Vertical slice

- Produce a short, polished example of the final experience.
- Create representative art, audio, and interface assets.
- Validate the production workflow.

## Phase 4: Production

- Build the planned content and features.
- Test regularly and refine the player experience.

## Phase 5: Release

- Complete final testing and performance work.
- Prepare store materials and release builds.
- Launch and gather player feedback.
